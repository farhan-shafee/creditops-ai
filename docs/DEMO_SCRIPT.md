# Two-minute interview demo

Use the working replay demo; no model key is needed. Reset any prior run before presenting.

| Time | Click | Say |
|---|---|---|
| 0:00 | Overview | “This is CreditOps AI, an independent portfolio system using entirely synthetic trading operations data. It demonstrates incident diagnosis rather than order execution.” |
| 0:15 | Run Incident Demo; Kafka pricing lag; Run Incident | “The simulated clock exposes a pricing consumer backlog over time. Quote age and RFQ latency deteriorate while negative controls remain healthy.” |
| 0:35 | Open the incident | “I can see impact, affected services, a timeline and correlated telemetry. Every observation has a stable evidence ID.” |
| 0:45 | Investigate with AI | “This public demonstration is labeled replay, generated by the real pipeline with its deterministic provider. Protected live mode uses a configurable model for diagnostic query planning and assessment.” |
| 1:00 | Watch completed trace | “The investigator inspects latency, Kafka, FIX, the database, changes, dependencies, historical incidents and runbooks. It has no restart, rollback or shell tool.” |
| 1:15 | Click a supporting evidence ID | “This is the actual diagnostic object supporting the conclusion. The server rejects invented citations. The RCA is a draft requiring human review.” |
| 1:35 | Evaluations | “These values were generated from 15 labeled synthetic cases, including three where the correct behavior is to abstain. They measure functional accuracy, retrieval and pipeline latency; they do not claim real MTTR reduction or live model performance.” |
| 1:55 | About / Architecture | “The local stack uses real PostgreSQL and Redpanda, while the public replay path avoids paid Kafka. The key design is keeping useful diagnosis separate from operational authority.” |

For a longer demo, reset the scenario and repeat FIX connectivity and database pool exhaustion. In the FIX case show sequence gaps and uncertain acknowledgements. In the DB case show the preceding release, saturated pool and normal CPU; explain that timestamp correlation still needs human causal verification.
